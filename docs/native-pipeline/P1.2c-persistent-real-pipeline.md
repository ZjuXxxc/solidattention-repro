# P1.2c: persistent real-Qwen overlap pipeline

P1.2c removes P1.2b's process-start I/O distortion and applies the paper's
cross-layer dependency order around the real Qwen layer executor.

This version deliberately reuses layer-0 weights/KV as a layer replica. It
proves persistent resource ownership and overlap with real Qwen compute; it is
not yet 28 distinct Qwen layers. P1.2d is reserved for that expansion.

## Persistent resources

One process retains:

- the liburing ring and registered file;
- CUDA pinned KV staging memory;
- current and next VRAM KV slots;
- CUDA compute and copy streams;
- cuBLAS handle;
- real Qwen layer weights and activation buffers.

The experiment performs 64 fixed-buffer reads per process. This separates the
first access from the steady ring/device state.

| I/O condition | Time |
|---|---:|
| first O_DIRECT read | about 7.4 ms |
| post-first persistent read mean | about 0.15 ms |
| persistent read median, formal 10-run aggregate | **0.147124 ms** |

P1.2b's 7.37 ms was therefore a cold first-access measurement, not a per-layer
steady-state SSD cost.

## Real overlap order

```text
SSD lane:      [ submit next selected KV ---------------- CQE ]
compute lane:  [ current Q ][ sparse attention ][ O/norm ][ current MLP ]
copy lane:                                         [ next KV H2D ]
critical wait:                                  [~0.0002 ms]
```

The next read is submitted after current KV H2D and before current Q/attention.
The host collects its CQE after current attention/O/norm have been queued. The
next KV H2D is then issued on the copy stream while current gate/up/SwiGLU/down
MLP runs on the compute stream.

No global `cudaDeviceSynchronize()` is used. The end audit waits on the current
compute result and the next-slot copy event.

## Formal result

10 processes, each warming/reusing one ring for 64 reads:

| Metric | Median |
|---|---:|
| persistent four-block SSD read | 0.147124 ms |
| next read submit-to-CQE interval | 1.301406 ms |
| exposed next-read wait | **0.000199 ms** |
| next-slot H2D | 0.027504 ms |
| real current-layer pipeline critical region | 1.444193 ms |
| final sparse-teacher maximum error | 1.79887e-4 |
| final sparse-teacher cosine | 0.999999988 |

The submit-to-CQE interval is intentionally larger than raw read service time:
it includes the interval during which the GPU is doing useful work. The exposed
wait is the critical-path metric.

## Remaining work

P1.2d must export all 28 distinct layer weights, per-layer real KV and teacher
hidden states; reuse bounded weight/KV slots; and pass hidden-state parity at
every layer. P1.3 then adds continuous token generation and managed KV
lifecycle/writeback.
