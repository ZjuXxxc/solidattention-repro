# P1.3b.1: real Qwen KV through the native lifecycle

P1.3b.1 replaces deterministic bit patterns with K/V produced by a real
Qwen3-0.6B forward pass over 544 token IDs. The exported contract is:

```text
28 layers x 544 tokens x {K,V} x 8 KV heads x 128 dims x FP16
```

Keys are post-RoPE. The fixture is 62,390,272 bytes with SHA256
`fdca4b7e56d2cbb9623f8ef1ed7ec6eeb92e0dd5921c14d6e11a01d4e088bcd6`.
The first 32 tokens seed each local tail and the remaining 512 exercise the
native lifecycle. Sealing, `O_DIRECT` writes, generation changes and liburing
verification all happen in C++.

## Five-run result

| Metric | Result |
|---|---:|
| real projected tokens / layers | 544 / 28 |
| sealed / verified blocks | 448 / 448 |
| representative query-head audits | 7,168 |
| final tail / generation | 32 tokens / 16 per layer |
| full lifecycle + verification median | 160.127803 ms |
| min / max | 154.393212 / 206.672850 ms |

## Honest boundary

The K/V values are genuine model outputs, but PyTorch performs projection and
fixture export before the native run. This proves real Qwen KV survives the
native lifecycle byte-exactly. It does not yet prove native K/V projection
parity or logits-driven autoregressive execution.

LD_LIBRARY_PATH="$PWD/vendor/nvidia-535.288/usr/lib/x86_64-linux-gnu" \

.venv/bin/python scripts/benchmark_cpp_p1_3b0.py --real-qwen
