# P1.2f: single-process 28-layer native chain

P1.2f removes P1.2e's per-layer process and hidden-file boundary. All 28
distinct sparse layers now execute inside one C++ process with:

- one CUDA context and compiled kernel module;
- one cuBLAS handle;
- one liburing ring and registered pinned KV buffer;
- fixed reusable activation, weight and KV device allocations;
- layer output copied device-to-device into the next layer input.

The compact TSV execution plan is generated from the ignored manifest and
contains layer directory, shared-KV byte offset and chain-specific block IDs.

## Correctness

Single-process recurrence exactly retains the P1.2e error profile:

| Metric | Result |
|---|---:|
| layers | 28 |
| maximum chain-input error | 7.6294e-5 |
| minimum chain-input cosine | 1.0 |
| maximum chain-output error | **9.1553e-5** |
| minimum chain-output cosine | **1.0** |

No intermediate hidden state is written to or read from disk.

## Five-run timing

| Component, 28-layer sum | Median |
|---|---:|
| FP32 weight files SSD/page cache → DRAM | 654.453545 ms |
| FP32 weights DRAM → VRAM | 101.224958 ms |
| selected FP16 KV fixed reads | 15.524927 ms |
| selected KV H2D | 0.914528 ms |
| real Qwen sparse compute | 7.024637 ms |
| complete single-process wall | **816.670344 ms** |

The result is diagnostic, not paper-comparable. SolidAttention keeps INT4 model
weights resident; P1.2f streams FP32 exported weights for each layer. Weight
I/O/H2D accounts for over 90% of the wall time and is now the dominant missing
paper assumption.

## Visualization

`P1.2f-single-process-qwen-chain-trace.json` shows five lanes for every layer:
weight read, weight H2D, KV read, KV H2D and real GPU compute. The current
implementation is deliberately serial, so the trace makes the weight bottleneck
obvious rather than drawing synthetic overlap.

## Remaining work

P1.2g must either keep quantized INT4 weights resident, matching the paper, or
use two bounded weight slots with asynchronous next-layer streaming. Only then
should P1.2c's next-KV read/H2D overlap be inserted into this true 28-layer
single-process chain.
