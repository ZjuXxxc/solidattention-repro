# P1.3c.5: merged prompt/decode selection and correction read

This version removes the candidate-only limitation of P1.3c.4. It rebuilds
the 512-token prompt representatives from real exported Qwen hidden states,
post-RoPE queries and FP16 keys, then merges 16 prompt blocks with decode block
16 at query-head granularity. The physical store contains all 17 blocks for
each of 28 layers rather than sparse holes.

The old four-block chain plan is the prediction. Selection over the new
generation is the oracle. Every miss is read separately through registered
fixed-buffer liburing and compared byte-for-byte with its store offset. The
whole selected set is independently read and verified as well.

| Metric | Result |
|---|---:|
| layers / candidates / budget | 28 / 17 / 4 blocks |
| new block selected | 28 / 28 layers |
| new block score top-4 | 28 / 28 layers |
| new block mean score rank | 1.07143 |
| prediction hits / misses | 68 / 44 |
| correction blocks verified | 44 / 44 |
| selected blocks verified | 112 / 112 |
| selection median (5 runs) | 1.22297 ms |
| selected read median (5 runs) | 5.60257 ms |
| correction read median (5 runs) | 3.27745 ms |

Block 16 is retained by the configured `local_blocks=1` rule, but its raw
representative score also ranks in the top four in every layer; those facts
are reported separately. This version stops after corrected data reaches
registered DRAM. P1.3c.6 must overwrite the evicted VRAM slots and make sparse
attention consume the corrected set.

```bash
./scripts/run_cpp_p1_3c5.sh
```
