# P1.2e: 28-layer native sparse hidden-state chain

P1.2e changes the P1.2d audit from independent dense-prefill inputs to a real
native sparse hidden-state chain:

```text
embedding hidden
 → native sparse layer 0 output
 → native sparse layer 1 input
 → ...
 → native sparse layer 27 output
```

Each native output is written as a 1024-value FP32 file and becomes the next
native process's input. The matching PyTorch chain independently performs the
same recurrence and recomputes selection from each chained query.

## Chained teacher

For every layer, the exporter records:

- chain input;
- normalized input and post-RoPE query;
- chain-specific selected block IDs;
- every attention/O/MLP intermediate;
- final chain output.

Prompt K/V remains the real dense-prefill per-layer FP16 store. This matches a
single decode token attending to an offloaded prompt context.

## Selection changes

The independent P1.2d queries selected `[0,13,14,15]` in every layer. Once
sparse hidden states are chained, layer 11 selects `[0,2,14,15]`. There are two
unique sets across the chain. This is evidence that the output of earlier
sparse layers actually affects later selection.

## Results

| Metric | Result |
|---|---:|
| chained layers | 28 |
| passing layers | 28/28 |
| maximum native chain-input error | 7.6294e-5 |
| minimum native chain-input cosine | 1.0 |
| maximum native chain-output error | **9.1553e-5** |
| minimum native chain-output cosine | **1.0** |
| unique selected block sets | 2 |

The largest output error occurs at layer 27. Error grows gradually rather than
showing a first catastrophic layer. All per-layer input/output errors are in
the published metrics.

## Execution boundary

P1.2e intentionally starts one controlled native executor process per layer.
This makes weight ownership and the first divergent layer easy to audit, but
process startup and repeated CUDA/NVRTC initialization make its 6.86 second
orchestration wall meaningless for serving throughput.

P1.2f must move the same chain into one native process, retain CUDA/cuBLAS and
liburing state, use bounded alternating weight/KV slots, and apply P1.2c's
cross-layer overlap to real next-layer offsets.
