# C1.3 — Device-resident output and sampled correctness audit

C1.3 removes the benchmark-only output copy from the normal attention path.
The output buffer remains owned by the accelerator backend so a future
`o_proj` kernel can consume it without returning through host memory.

## Audit policy

The 64-operation experiment uses `--audit-every 16`. Operations
`0, 16, 32, 48` and the final operation `63` copy output to the host and compare
it with the CPU oracle. The remaining 59 operations synchronize on kernel
completion but do not issue D2H.

Metrics record:

- `device_resident_output=true`;
- `audit_every=16`;
- `audit_operations=5`;
- mean D2H across all operations, including zero for non-audited operations.

This is sampled validation, not removal of validation.

## Three-run result

C1.2 is the persistent-buffer baseline. Values are mean ± sample standard
deviation across three 64-operation runs.

| Backend/version | Complete backend wall | Mean audit D2H |
|---|---:|---:|
| CUDA C1.2 | 0.090433 ± 0.000206 ms | 0.007989 ms |
| CUDA C1.3 | 0.084125 ± 0.000318 ms | 0.001579 ms |
| SYCL CPU C1.2 | 0.229556 ± 0.016728 ms | 0.018361 ms |
| SYCL CPU C1.3 | 0.191941 ± 0.022294 ms | 0.001529 ms |

CUDA wall time falls 6.98% and mean D2H falls 80.24%. SYCL CPU wall time falls
16.39% and mean D2H falls 91.67%.

All 15 sampled audits across the three runs for each backend retain maximum
absolute error `2.6077e-8` and cosine `1.0`.

## Why D2H does not fall by exactly 59/64

Only 5/64 operations copy output, but a no-copy path still records/synchronizes
kernel completion. CUDA's event bookkeeping remains in the backend call, while
SYCL event duration is reported as zero for no-copy operations. Copy latency,
submission overhead and averaging therefore do not scale as one ideal constant.

## Remaining artificial work

- The CPU reference is constructed before the benchmark and sampled audits
  still allocate a host output vector.
- Every operation still transfers the same 512 KiB selected KV buffer.
- The output is resident but is not yet consumed by a real output projection.
- Attention still uses the two-pass local probability array, not online
  softmax.
- Selection and real Qwen layer execution are absent.

C1.4 should add an accelerator-side output consumer/checksum kernel to verify
the resident dependency without D2H, then compare online-softmax variants.
